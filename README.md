# Firewall Configuration and Testing

This repository contains documentation for Task 10: Firewall Configuration & Testing.  
The task focuses on understanding firewall concepts, configuring firewall rules, testing connectivity, and analyzing their impact on system security.

## Objective
- Learn basic firewall concepts
- Configure firewall rules
- Allow and block specific ports
- Test network connectivity
- Observe firewall logs
- Block a malicious IP address
- Document firewall rules and results

## Tools Used
- UFW / Windows Defender Firewall
- iptables (alternative)
- Command line interface

## Task Summary
Firewall rules were configured to control inbound and outbound network traffic.  
Specific ports were allowed for essential services, while unnecessary ports were blocked.  
Connectivity tests were performed to verify rule effectiveness.  
Firewall logs were analyzed to monitor allowed and denied traffic.

## Key Learnings
- Difference between stateful and stateless firewalls
- Importance of inbound and outbound rules
- Role of firewalls in network security
- Impact of firewall misconfiguration

## Outcome
This task improved understanding of firewall management and basic network security practices.
